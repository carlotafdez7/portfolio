## Project Concept

### What are you building?

I am building a personal portfolio website to showcase my work as a graphic designer, illustrator and photographer.  
The site presents different disciplines (editorial, illustration, photography, motion graphics and branding) through a clean, visual and structured layout.

### Who is it for?

The portfolio is aimed at potential clients, creative studios and academic contexts, as well as anyone interested in visual design, illustration and analog photography.

### Why does it matter?

This project matters because it represents both my professional identity and my learning process.  
It allows me to present my work in a coherent way while applying web design principles such as responsive design, accessibility and modern CSS architecture.

## Design Direction

### Visual Style

The visual style is minimal, dark-themed and focused on typography and imagery.  
The design prioritizes clarity, rhythm and hierarchy, allowing the projects to be the main focus.

### Color Palette

- Dark neutral backgrounds  
- Soft light text for contrast  
- Accent color for interactive elements and highlights  

### Typography

The project uses a system-font-based approach combined with a fluid typographic scale using `clamp()`.  
This ensures performance, readability and smooth scaling across devices.

### Inspiration / References

- Contemporary portfolio websites with a strong editorial approach  
- Minimal design systems focused on typography  
- Photography and design portfolios with dark UI and subtle animations
